## 📋 Vercel Naming Rules

Project names must be:
- ✅ Up to 100 characters long
- ✅ Lowercase only
- ✅ Can include: letters, digits, '.', '_', '-'
- ❌ Cannot contain: '---' sequence
- ❌ Cannot contain: uppercase letters

## 🚀 How to Change Project Names

If you need to update the project names:

### 1. Update vercel.json files:
```json
{
  "name": "your-new-project-name",
  // ... rest of config
}
```

### 2. Update in Vercel Dashboard:
- Go to project settings
- Change project name
- Update any references

### 3. Update environment references:
- Update any hardcoded URLs
- Update CORS origins if needed
- Update documentation
