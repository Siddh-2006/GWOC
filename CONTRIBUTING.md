# Contributing to MindSettler 🚀

First off, thank you for considering contributing to MindSettler! It's people like you who help make this digital sanctuary better for everyone.

## 🌈 Code of Conduct
By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## 🛠️ How Can I Contribute?

### Reporting Bugs
- Use the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
- Provide a clear, descriptive title.
- Describe the exact steps to reproduce the issue.

### Suggesting Enhancements
- Use the [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).
- Explain why this enhancement would be useful to MindSettler users.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Make sure your code lints.
5. Issue that pull request!

## 🏗️ Development Setup
Reference the [README.md](README.md) for detailed setup instructions for the Frontend, Backend, and RAG services.

## 🎨 Style Guides
- **JavaScript**: We follow standard ES6+ patterns.
- **CSS**: We use Tailwind CSS. Maintain consistent spacing and theme colors.
- **Git**: Use descriptive commit messages (e.g., `feat: add RAG ingestion status`, `fix: header alignment on mobile`).

## 🛡️ Security
If you find a security vulnerability, please do **not** open an issue. Follow the instructions in our [Security Policy](SECURITY.md).
