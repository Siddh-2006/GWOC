# Security Policy 🛡️

MindSettler takes the security and privacy of our users extremely seriously. Being a mental health platform, maintaining a safe harbor is our top priority.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Yes             |
| < 1.0   | ❌ No              |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report vulnerabilities by emailing the core team at **security@brightweb.com** (replace with your actual business email).

### What to include:
- A description of the vulnerability.
- Steps to reproduce (or a proof-of-concept script).
- Potential impact.

### Our Commitment:
- We will acknowledge receipt of your report within 48 hours.
- We will provide a detailed response including a timeline for a fix.
- We will notify affected users if necessary, once a fix is in place.

Thank you for helping keep MindSettler safe! 💖
